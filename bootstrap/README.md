# ImageLab bootstrap source bundle

Эта папка используется только для первоначального запуска Windows Zero-Trust Gate.

## Обязательный файл

Загрузите сюда файл `imagelab-source.zip`. Его SHA-256 должен совпадать с `imagelab-source.sha256`.

Workflow сначала проверяет контрольную сумму, затем распаковывает исходники в изолированную рабочую папку. Непроверенный ZIP не исполняется.

## Результат bootstrap-проверки

Первичный workflow выполняет:

- проверку состава и SHA-256 исходного пакета;
- G0 source gate;
- критические unit/regression tests;
- сборку точного Windows-кандидата;
- установку кандидата в Windows runner;
- управление установленным интерфейсом через Playwright;
- проверку созданных PNG/SVG и lineage;
- независимый повторный Windows-прогон.

Bootstrap никогда не публикует установщик как пользовательский релиз. Пока не проверено обновление реальной предыдущей версии и rollback, итог остаётся `RELEASE_BLOCKED`.
