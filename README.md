# ImageLab by LarannA

Публичный репозиторий приложения ImageLab и его Zero-Trust Release Gate.

## Правило выпуска

Пользовательский установщик может публиковаться только после прохождения ворот G0–G8 в GitHub Actions и получения артефакта `ImageLab-RELEASE-AUTHORIZED`.

До полного прохождения Windows-проверок статус проекта: `RELEASE_BLOCKED`.

## Проверяемые функции

- изменение физического размера и PPI;
- переключение между созданными изображениями;
- сохранение lineage входного файла;
- удаление фона;
- извлечение принта;
- полутон;
- векторизация SVG;
- экспорт;
- чистая установка Windows;
- обновление поверх предыдущей версии;
- rollback после искусственного сбоя;
- независимый повторный Windows-прогон.

## Публичный репозиторий

Не размещать секреты, ключи, персональные данные, пользовательские проекты и закрытые коммерческие датасеты.
